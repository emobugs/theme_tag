# Локална работа: пълно ръководство

Всичко нужно, за да пуснеш, тестваш и променяш играта на собствения си компютър (Windows, macOS или Linux).

> Работно име: **Emoji Колизеум**. Логото и името в overlay-а са в `game/Overlay.tsx` (блок `.logo`), а заглавието на страниците е в `app/layout.tsx`.

---

## 1. Какво ти трябва

| Инструмент | Версия | Защо |
|---|---|---|
| [Node.js](https://nodejs.org) | 20.12 или по-нова (препоръчвам 22 LTS) | върти overlay-а и bridge-а |
| [Git](https://git-scm.com) | всяка | за да свалиш кода |
| Chrome или Edge | всяка | за да гледаш overlay-а |
| TikTok LIVE Studio или OBS | последна | за самото излъчване |

Провери версията на Node:

```bash
node -v    # трябва да е v20.12.0 или повече
```

---

## 2. Сваляне на проекта

Проектът е в папка `emoji-colosseum/` в репото `emobugs/theme_tag`, в клона `claude/tiktok-live-gifts-idea-sqfeq0`.

```bash
git clone https://github.com/emobugs/theme_tag.git
cd theme_tag
git checkout claude/tiktok-live-gifts-idea-sqfeq0
cd emoji-colosseum
npm install
```

`npm install` отнема около минута. Всички команди по-долу се пускат от папка `emoji-colosseum/`.

## 3. Настройка (`.env`)

Копирай примерния файл:

```bash
# macOS / Linux / PowerShell
cp .env.example .env

# Windows cmd
copy .env.example .env
```

| Променлива | Пример | Какво прави |
|---|---|---|
| `TIKTOK_USERNAME` | `digitaleffect` | TikTok профилът, от който се четат подаръците (без `@`). Празно = симулатор. |
| `EULER_API_KEY` | празно | По избор. Ключ от eulerstream.com, ако безплатният лимит на библиотеката спре да стига. |
| `BRIDGE_PORT` | `8787` | Портът на bridge-а. Ако го смениш, отваряй overlay-а с `?ws=ws://localhost:НОВ_ПОРТ`. |
| `MODE` | `auto` | `auto` = TikTok, ако има username, иначе симулатор. `sim` = винаги симулатор. `tiktok` = само TikTok. |
| `DATA_FILE` | `data/stats.json` | По избор. Къде се записват отборите и класациите. |

`.env` не се качва в git, затова можеш спокойно да пазиш ключове там.

## 4. Пускане

### Команди

| Команда | Какво пуска | Кога |
|---|---|---|
| `npm run dev` | overlay (Next.js dev) + bridge, рестартират се при промяна на кода | докато пишеш код |
| `npm run dev:sim` | същото, но bridge-ът винаги е със симулирани зрители | тест без TikTok |
| `npm run build` | компилира overlay-а | преди `npm start` |
| `npm start` | overlay (production) + bridge | реален лайф |
| `npm run bridge` / `npm run bridge:sim` | само bridge-а | ако overlay-ът е на друга машина |
| `npm run tune` | балансов тест без браузър | след промяна в `shared/config.ts` |
| `npm run typecheck` | проверка на TypeScript | преди commit |

Спиране: `Ctrl + C` в терминала (спира и двата процеса, а класациите се записват).

### Адреси

| Адрес | Какво е |
|---|---|
| `http://localhost:3000` | начална страница с връзки |
| `http://localhost:3000/overlay` | overlay-ът (това слагаш в LIVE Studio / OBS) |
| `http://localhost:3000/overlay?offline=1` | демо само в браузъра: без bridge и без TikTok |
| `http://localhost:3000/control` | контролен панел: тестови подаръци и симулатор |
| `http://localhost:8787/health` | статус на bridge-а (JSON) |

### Параметри на overlay-а

Комбинират се с `&`, например `/overlay?debug=1&vol=0.3`.

| Параметър | Действие |
|---|---|
| `offline=1` | симулатор в браузъра, без bridge |
| `ws=ws://192.168.1.20:8787` | bridge на друга машина |
| `mute=1` | без звук |
| `vol=0.3` | сила на звука (0 до 1, по подразбиране 0.5) |
| `tts=0` | без глас при победи и големи подаръци |
| `debug=1` | винаги показва статуса на връзката горе вляво |

## 5. Тестване стъпка по стъпка

### 5.1 Само играта (30 секунди)

```bash
npm run dev
```

Отвори `http://localhost:3000/overlay?offline=1`. Трябва да видиш 8 емоджита, които се бият, отброяване и симулирани подаръци.

### 5.2 Целият път: bridge, overlay и контролен панел

```bash
npm run dev:sim
```

1. Отвори `http://localhost:3000/overlay?debug=1`. Горе вляво трябва да пише зелено "симулатор (без TikTok)".
2. В друг таб или на телефона отвори `http://localhost:3000/control`.
3. Избери отбор, натисни "💣 300" и гледай overlay-а: бомба пада върху лидера.
4. "👑 10000" приключва рунда моментално и записва името в Зала на славата.
5. Бутонът "Спри симулатора" оставя само твоите тестови събития.

### 5.3 Контролен панел от телефона

Телефонът и компютърът трябва да са в една Wi-Fi мрежа.

1. Намери IP-то на компютъра: на Windows `ipconfig` (IPv4 Address), на macOS `ipconfig getifaddr en0`.
2. На телефона отвори `http://192.168.X.X:3000/control`.
3. Ако Windows покаже прозорец на защитната стена за Node.js, разреши "Private networks".

### 5.4 С истински TikTok лайф

1. В `.env` попълни `TIKTOK_USERNAME`.
2. `npm run build`, после `npm start`.
3. Пусни лайфа в TikTok (LIVE Studio или телефона).
4. В терминала bridge-ът пише `на живо: @име (room ...)`. Докато не си на живо, пише "не е на живо" и опитва отново на всеки 20 секунди. Това е нормално.
5. Напиши емоджи в чата на лайфа от друг профил: в overlay-а излиза `+Име` до емоджито.

## 6. Излъчване

### TikTok LIVE Studio (Windows)

1. `npm start` (или `npm run dev:sim` за тест).
2. LIVE Studio → портретен режим (вертикален).
3. **Add source → Link** (или Browser) → `http://localhost:3000/overlay`, ширина **1080**, височина **1920**.
4. Разпъни източника да покрие целия кадър.
5. Звукът идва от самия източник. Ако не се чува, провери миксера в LIVE Studio.

### OBS (за Twitch, YouTube или TikTok с RTMP ключ)

1. **Settings → Video**: Base и Output resolution **1080x1920**, 30 FPS.
2. **Settings → Output**: Bitrate 4500-6000 Kbps. Енкодер: NVENC (NVIDIA), QuickSync (Intel) или AMF (AMD), ако го има; иначе x264 veryfast.
3. **Sources → + → Browser**: URL `http://localhost:3000/overlay`, Width 1080, Height 1920, отметни **Control audio via OBS**.
4. Twitch и YouTube предпочитат хоризонтален кадър. Вертикалният 1080x1920 работи, но ще има черни ленти отстрани. За тях може да се направи хоризонтален layout (виж раздел 10).

## 7. Как е устроен проектът

```
emoji-colosseum/
├── shared/               общ код за bridge-а и браузъра
│   ├── config.ts         ВСИЧКИ настройки: отбори, нива подаръци, баланс
│   ├── events.ts         типовете на събитията и съобщенията
│   ├── room.ts           кой в кой отбор е, класации, дневни/общи победи
│   └── sim.ts            симулирани зрители
├── bridge/               Node процес на порт 8787
│   ├── server.ts         WebSocket сървър, контролен панел, симулатор
│   ├── tiktok.ts         връзка с TikTok LIVE (tiktok-live-connector)
│   └── store.ts          запис в data/stats.json
├── game/                 играта (браузър)
│   ├── engine.ts         физика и правила (Matter.js), без DOM
│   ├── render.ts         рисуване в canvas
│   ├── Overlay.tsx       целият екран 1080x1920, анимации с GSAP
│   ├── audio.ts          синтезирани звуци и TTS
│   └── feed.ts           връзка с bridge-а или офлайн симулатор
├── app/                  Next.js страници: /, /overlay, /control
├── scripts/tune.ts       headless тест на баланса
└── data/stats.json       отбори и класации (създава се сам, не е в git)
```

### Пътят на един подарък

1. TikTok праща събитие → `bridge/tiktok.ts` го чете. При серия от рози праща само новите, за да реагира играта веднага, а не в края на серията.
2. `shared/room.ts` намира отбора на зрителя (или го слага в най-малкия), добавя монетите в класациите.
3. Bridge-ът праща нормализирано събитие `{ kind: 'gift', team, coins, count }` по WebSocket.
4. `game/engine.ts` избира нивото по `coins` от `TIERS` и изпълнява ефекта `count` пъти (максимум 60).
5. В края на рунда overlay-ът праща победителя обратно, bridge-ът го записва.

Ако overlay-ът е отворен на две места (OBS и браузър), само първият (primary) докладва победите, за да не се броят двойно.

## 8. Промени по играта

Всичко е в `shared/config.ts`. След промяна: `npm run tune` (без подаръци) и `npm run tune -- 20 --live` (със симулирани зрители).

### Най-важните настройки

| Настройка | Сега | Ефект |
|---|---|---|
| `roundSec` | 240 | продължителност на рунда (сек) |
| `rageSec` / `rageMultiplier` | 60 / 2.5 | последните N секунди щетите са умножени |
| `hitDamage` | 0.06 | колко боли един сблъсък. По-голямо = по-кратки рундове |
| `regenPerSec` | 0.35 | самолекуване, когато не е ударен 2.5 сек |
| `maxRadius` / `growFactor` | 130 / 1.035 | колко може да порасне и с колко на роза |
| `shieldMs`, `dashMs` | 15000, 3000 | продължителност на щит и ускорение |
| `bombDamage`, `meteorDamage` | 0.35, 0.55 | дял от максималния живот |
| `reviveHp` | 0.35 | с колко живот се връща елиминиран отбор |
| `likeHeal` | 0.12 | живот за един лайк |

Ориентир за `hitDamage` при 8 бота без подаръци: 0.05 ≈ 2:35 мин, 0.06 ≈ 2:10, 0.09 ≈ 1:30.

### Смяна на нивата на подаръците

В `TIERS` промени `min` (монети за един подарък), `label` и `icon`. `action` трябва да е едно от: `grow`, `dash`, `minions`, `shield`, `bomb`, `meteor`, `crown`. Таблицата в overlay-а и бутоните в контролния панел се обновяват сами.

### Смяна или добавяне на отбор

В `TEAMS` всеки отбор има `id` (латиница, уникален), `emoji`, `name`, `color` и `aliases` (думи, с които се влиза от чата). Overlay-ът е направен за 8 отбора (решетка 4x2). При повече трябва да се пипне `.teams` в `app/globals.css`.

### Нулиране на класациите

Спри bridge-а и изтрий `data/stats.json`. При офлайн демото данните са в браузъра: DevTools → Application → Local Storage → изтрий `emoji-colosseum:offline-state`.

## 9. Проблеми и решения

| Симптом | Причина и решение |
|---|---|
| `EADDRINUSE :3000` или `:8787` | Нещо вече държи порта. Затвори другия терминал или смени порта (`next dev -p 3001`, `BRIDGE_PORT`). |
| Червено "няма връзка с bridge" | Bridge-ът не върви. Пусни го с `npm run dev` / `npm start`, или ползвай `?offline=1`. |
| Квадратчета вместо емоджита | Липсва шрифт за емоджи (основно на Linux): `sudo apt install fonts-noto-color-emoji`. |
| Няма звук в браузъра | Браузърите искат един клик. Натисни "🔊 Кликни за звук". В OBS и LIVE Studio тръгва сам. |
| Няма глас (TTS) | Няма инсталиран български глас. Windows: Settings → Time & language → Speech → добави Български. Не е задължителен. |
| Bridge пише "не е на живо" | Лайфът не е пуснат или потребителското име е грешно. Опитва отново на всеки 20 сек. |
| Подаръци идват със закъснение или изобщо не идват | Библиотеката за TikTok е неофициална. Обнови я (`npm i tiktok-live-connector@latest`) или добави `EULER_API_KEY`. |
| Победите се броят двойно | Overlay-ът е отворен на две места при различни bridge-ове. Остави един bridge. |
| Overlay-ът е мъничък в OBS | Размерът на Browser Source трябва да е точно 1080x1920. |

## 10. Twitch и YouTube: какво работи и какво не

Сега bridge-ът чете **само TikTok**. Играта (`game/`) не зависи от платформата: тя приема нормализирани събития, затова за всяка платформа е нужен само нов файл в `bridge/`, подобен на `tiktok.ts`.

| | TikTok | Twitch | YouTube |
|---|---|---|---|
| Офлайн демо (`?offline=1`) | ✅ | ✅ | ✅ |
| Чат → влизане в отбор | ✅ | нужен адаптер (лесен) | нужен адаптер (по-сложен) |
| "Подаръци" | Gifts | Bits, абонаменти | Super Chat, Super Stickers, членства |
| Условие за подаръци | LIVE достъп | Affiliate статут | YouTube Partner Program |

Ориентировъчно 100 Bits ≈ 1 долар ≈ 100 TikTok монети, затова нивата от `TIERS` могат да се ползват почти 1:1. Абонамент в Twitch ≈ 500 монети (бомба). Super Chat за 1 долар ≈ 100 монети.
