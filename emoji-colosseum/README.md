# Emoji Колизеум

Faceless TikTok LIVE игра, която се върти 24/7.

**Пълно ръководство за локална работа: [docs/local-setup.md](docs/local-setup.md)**

 Осем емоджи отбора се бият в арена с физика. Зрителите влизат в отбор, като пишат емоджи в чата, а подаръците задействат ефект според стойността си.

## Как се играе

**Влизане в отбор:** зрителят пише емоджи (🔥 😂 💀 🐸 👽 🤡 🦄 🐷) или думата ("жаба", "огън"...). Ако прати подарък без да е избрал, влиза автоматично в най-малкия отбор.

**Подаръци** (по стойност на един подарък; при серия ефектът се повтаря):

| Монети | Ефект |
|---|---|
| 1+ | 🌹 емоджито расте (+живот) |
| 5+ | ⚡ ускорение, удря x1.8 |
| 20+ | 🐣 3 миньона, които гонят враговете |
| 100+ | 🛡️ щит за 15 секунди |
| 300+ | 💣 бомба върху лидера |
| 1000+ | ☄️ метеор: удря всички врагове, трие миньоните им |
| 10 000+ | 👑 краде короната: моментална победа + Зала на славата |

- Всеки подарък за елиминиран отбор го **връща в играта**.
- ❤️ лайковете лекуват отбора на зрителя, 📤 споделянето дава +10% и растеж, ➕ последването дава миньон.
- Рундът трае 4 минути, последната минута е **ЯРОСТ** (щети x2.5, без регенерация). Печели последният оцелял или този с най-много живот.
- Без зрители ботовете се бият сами (рунд от около 2 минути), така екранът никога не е статичен.

Всички числа са в `shared/config.ts`. След промяна пусни `npm run tune` (без подаръци) или `npm run tune -- 20 --live` (със симулирани зрители), за да видиш колко траят рундовете.

## Архитектура

```
TikTok LIVE ──► bridge (Node, порт 8787) ──WebSocket──► overlay (Next.js, /overlay)
                  │  отбори, класации                        │  физика (Matter.js), canvas, GSAP
                  └─ data/stats.json                         └─ докладва победителите обратно
контролен панел (/control) ──► bridge  (тестови подаръци, симулатор)
```

- `bridge/` чете събитията с [tiktok-live-connector](https://github.com/zerodytrash/TikTok-Live-Connector) (неофициална библиотека), пази кой в кой отбор е и записва класациите в `data/stats.json`. Ако overlay-ът се презареди, нищо не се губи.
- `game/` е самата игра. Логиката (`engine.ts`) е без DOM и може да се тества headless.
- `shared/` е общият код: конфигурация, типове, отбори и класации, симулатор.

## Пускане

Изисква Node.js 20.12+.

```bash
cd emoji-colosseum
npm install
cp .env.example .env      # попълни TIKTOK_USERNAME
npm run build
npm start                 # overlay на :3000, bridge на :8787
```

- За разработка: `npm run dev`. Със симулирани зрители, без TikTok: `npm run dev:sim`.
- Отвори `http://localhost:3000/overlay?offline=1`, за да видиш демо само в браузъра, без bridge.
- Отвори `http://localhost:3000/control`, за да пращаш тестови подаръци. Работи от телефон в същата мрежа: `http://IP-на-компютъра:3000/control`.

### Параметри на overlay-а

| Параметър | Действие |
|---|---|
| `?offline=1` | демо със симулатор в браузъра |
| `?ws=ws://1.2.3.4:8787` | bridge на друга машина |
| `?mute=1`, `?vol=0.3` | звук |
| `?tts=0` | изключва гласа (говори само при победи и големи подаръци, ако има български глас) |
| `?debug=1` | показва статуса на връзката |

## Излъчване

### Вариант А: TikTok LIVE Studio (Windows), препоръчителен

1. `npm start` на същия компютър.
2. В LIVE Studio: вертикален (портретен) режим, **Add source → Link/Browser**, URL `http://localhost:3000/overlay`, размер **1080x1920**.
3. Звукът идва от browser source-а. Ако е тихо, провери аудио миксера на LIVE Studio.

### Вариант Б: OBS + RTMP ключ

Само ако акаунтът ти има достъп до stream key (не всички акаунти го получават).
Browser Source 1080x1920, URL `http://localhost:3000/overlay`, отметка "Control audio via OBS". Canvas 1080x1920, 30 fps, 4-6 Mbps.

### Вариант В: headless Linux VPS (Hetzner)

Xvfb + Chromium в kiosk режим + OBS с RTMP ключ. Нужен е шрифт за емоджи, иначе ще виждаш квадратчета:

```bash
sudo apt install fonts-noto-color-emoji xvfb obs-studio chromium
```

Пусни `npm start` и bridge-а с `pm2` или `systemd`, за да се рестартират сами.

### TikTok част на екрана

TikTok покрива горните ~180px (профил, зрители) и долния ляв ъгъл (чат). Затова таймерът, отборите и арената са в горната и средната част, а класациите са най-отдолу. Може да не се виждат, когато чатът е активен.

## Какъв сървър ти трябва

| Какво върви на сървъра | 2 vCPU / 2 GB | 4 vCPU / 8 GB |
|---|---|---|
| Само bridge + overlay (стриймваш от друга машина) | ✅ с много запас (~200 MB RAM) | излишно |
| Пълно 24/7 излъчване от VPS (Chromium + OBS + x264 1080x1920) | ❌ не стига | ⚠️ минимум; по-добре dedicated vCPU или 720x1280 |

- **Ако bridge-ът е отделно от стрийма**, 2 ядра и 2 GB стигат с голям запас. Hostinger Node приложенията не са подходящи, защото bridge-ът трябва да държи постоянна връзка с TikTok, а shared хостингът приспива и рестартира процесите.
- **Ако излъчваш от сървъра**, без видеокарта процесорът кодира видеото софтуерно. Само x264 на 1080x1920 при 30 fps изяжда 2-3 ядра, Chromium рендерира без GPU, а Chromium + OBS заедно ползват около 1.5-2 GB RAM. Значи **минимум 4 ядра и 8 GB**, за предпочитане dedicated vCPU (при Hetzner: CCX серията, не споделените CPX/CX). На споделени ядра при 24/7 натоварване ще има накъсване.
- **Най-евтиният стабилен вариант за 24/7** е мини PC вкъщи (например Intel N100, 16 GB, Windows) с LIVE Studio. Хардуерният енкодер (Quick Sync) кодира почти без натоварване на процесора, а ти трябват само ~6 Mbps upload. Проверявай актуалните цени и конфигурации, защото Hetzner ги сменя.

## Рискове

- **Неофициална библиотека:** tiktok-live-connector не е официално API. Когато TikTok смени нещо, може да спре, докато не излезе обновление. Подписването минава през Euler Stream: с безплатния лимит работи, но при проблеми си вземи API ключ (`EULER_API_KEY`).
- **Без реални награди:** никакви пари, кодове или физически награди срещу подаръци. Короната и класациите са само символични.
- **Правила на TikTok:** правилата за LIVE (неоригинално съдържание, игри с подаръци, минимални изисквания за акаунта) се сменят. Провери ги преди пускане. Тази игра реагира на живо на зрителите и не е запис.
